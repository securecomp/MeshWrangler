# Changelog

## v1.1.0 — Release candidate (not published)

- SEC-01–SEC-06: browser/output escaping, terrain-request guard, filesystem containment and optional application index `deviceId` handling.
- FUNC-01: interactive dark Leaflet mapping in Offline mode, validated in Safari 26.5.
- Reconcile independently versioned components and add predecessor-comparison version, checksum and permission checks.
- SEC-07 dependency review completed; final publication gate pending.

## v1.0.0 — Initial release

- Export historical Meshtastic Apple application node databases to CSV and JSON.
- Consolidate observations across multiple device snapshots while retaining source attribution.
- Report node-name variants and public-key conflicts.
- Explore historical node geography, activity and related metadata in the HTML Explorer (v0.9.11; automatic street-map initialization and neutral global startup view).
- Document third-party dependencies, privacy limitations and platform compatibility.

- Component-level version changes: Explorer v0.9.11 -> v0.9.12; master exporter v1.0.0 -> v1.1.0; snapshot exporter v2.0.0 -> v2.1.0. Unchanged source components retain their versions.
