# Changelog

## v1.0.0 — Initial release

- Export historical Meshtastic Apple application node databases to CSV and JSON.
- Consolidate observations across multiple device snapshots while retaining source attribution.
- Report node-name variants and public-key conflicts.
- Explore historical node geography, activity and related metadata in the HTML Explorer (v0.9.11; automatic street-map initialization and neutral global startup view).
- Document third-party dependencies, privacy limitations and platform compatibility.
